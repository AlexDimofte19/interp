▶ How to Use

Export a trajectory first:

python scripts/jlens_viewer_export.py --csv <jlens csv> \
  --trajectory-paths <trajectories dir> --direction-tokens direction_tokens.json \
  --sizes 11 --complexities 0.0 --runs 0

Then hit 📂 Load Folder and pick <out-dir>/size11_comp0.0_run0 (picking the export root works too — a dropdown appears to choose the trajectory).

  • Lens predictions by layer shows the Jacobian-lens top-20 tokens at every layer for the selected reasoning token. Words belonging to UP / DOWN / LEFT / RIGHT are tinted with that action's color (lists come from direction_tokens.json at export time).
  • Action-token rank by layer beneath it gives the exact rank of each action token (0 = argmax, out of ~201k vocabulary). Click a cell to jump to that layer and action.
  • Action rank heatmap: x = reasoning token position, y = layer (L0 at the bottom). Brighter = the selected action's token ranks higher. Click any cell to select that position and layer — the token is highlighted in the Model Output pane and the table above updates.
  • Top-20 direction density: same axes, brightness = how many of the 20 lens predictions at that cell are words for the selected action (0–20). Fully dark = none.
  • Clicking a reasoning token in Model Output moves the heatmap crosshair. Arrow keys move the selection (←/→ position, ↑/↓ layer) once a heatmap has focus.
