Controls

  • Load JSON: Upload a trace file in the format described in the README
  • Play/Pause/Step: Control the animation through agent steps
  • Speed Slider: Adjust animation speed
  • ⚙️ Grid & Model Params: View grid and model configuration

Token Visual Indicators

  • Colored Underlines indicate token groups:
    • Blue = Analysis tokens
    • Orange = Final answer tokens
    • Green = Action tokens
    • Gray = Template tokens
  • Yellow highlight = Token has next-token probabilities (hover to view)
  • Purple highlight = Token has probe data (hover/click to view decoded grid)

Interactive Features

  • Hover over tokens: View token ID, probabilities, and probe layer selector
  • Click tokens with probes: Pin the decoded grid to keep it visible
  • Hover over decoded grid tiles: View probability distributions for each tile type
  • Layer selector: Switch between different model layers (in token tooltip)
  • Collapsible sections: Click headers to expand/collapse Prompt Template, Model Output, and this Help section

Decoded Grid

When hovering or clicking a token with probe data, the decoded grid shows the model's internal representation of the grid state. Each tile shows the predicted tile type (based on highest probability). Tiles marked with "X" have no probe data available.
