▶ How to Use

Getting Started with Trace Viewer

To use Trace Viewer, upload a JSON trace file in the format described in the demo README. Once uploaded, the first grid state will become visible, alongside two prompt and model output sections containing input/output tokens for the current trace step.

Use the buttons ▶️ Play, ⏸️ Pause, ⏩ Next, ⏪ Back and 🔄 Reset to move across trace steps, and use the slider to control animation speed. A white arrow on the agent tile (A) indicates the predicted action direction from the model. The arrow points in the direction predicted by the agent. A summary of grid and model parameters is available in the ⚙️ Config tab.

Token Visual Indicators

  • Colored Underlines indicate token types:
    • Blue = Reasoning tokens
    • Orange = Final answer tokens
    • Green = Tokens matching valid output actions
    • Gray = Special tokens used by the tokenizer
  • Colored Highlights indicate the token has additional information visible upon hovering:
    • Yellow = Prediction probabilities
    • Purple = Probing results

Tokens can be hovered to show an info tooltip with next-token probabilities displayed as bar charts. Tokens with probe information will also display a decoded grid showing the model's internal representation of tile types. Tiles marked with "X" have no probe data available. Clicking on a token with probe information pins the decoded grid for further inspection. Use the layer selector dropdown above the decoded grid to switch between different model layers. Hovering on decoded grid tiles shows the prediction probabilities for all tile classes as bar charts.
